# 育儿小饭桌 · 沉浸式网页解谜游戏

## 游戏简介

你在深夜刷到一个匿名论坛的爆料帖：

> 建设路那家"育儿小饭桌"，强迫孩子喝一种蓝色的"YC营养液"，喝完就犯困；有孩子被霸凌没人管；上个月半夜还有人看到消防车停在店门口……

帖子里附了那家机构的官网链接。网站看起来一切正常——温馨的饭菜、热情的师资、满屏的家长好评。

但真的是这样吗？

你将扮演一名普通网民，**像浏览真实网站一样**，在这家托管机构的官网里翻找蛛丝马迹：点开的每一张图片、加载的每一条评价、甚至网页源代码里的每一行注释，都可能是通往真相的钥匙。

- 类型：沉浸式网页解谜 / 剧情推理
- 时长：约 15 - 30 分钟
- 结局：4 个（含 1 个隐藏真结局）
- 特色：无任何游戏化 UI，整个游戏就是一个"真实的网站"

## 运行方式

纯静态网页，无需安装任何东西：

- **方式一（推荐）**：双击打开 `forum.html`（论坛爆料帖，游戏的起点）
- **方式二**：本地起个静态服务，体验更接近真实网站
  ```bash
  python -m http.server 8000
  # 然后浏览器访问 http://localhost:8000/forum.html
  ```

推荐浏览器：Chrome / Edge / Firefox。

## 玩法教程（无剧透）

1. **从论坛开始**。先读 `forum.html` 的爆料帖和回复，楼里藏着调查方向。
2. **把它当成真网站用**。官网五个栏目（首页 / 服务介绍 / 菜品展示 / 家长反馈 / 联系我们）都要逛，和真实网站一样的点击、翻页、看大图，都可能触发线索。
3. **注意"不对劲"的细节**：每周三的菜单、欲言又止的匿名评价、页脚不起眼的灰色小字……
4. **看源码**。真实的网民会右键"查看网页源代码"，你也应该试试——有些页面里，网管把不该留的东西留在了注释里。
5. **多处对照**。密码不会直接写出来，而是需要把 A 页的规则和 B 页的数字拼起来。
6. **卡住了就硬试**。密码输入错误 3 次后，页面会给出提示，不存在死胡同。
7. **论坛值得多看一眼**。某个不起眼的"话题标签"，决定了你能否打出真结局。

## 文件结构

```
├── forum.html          # 匿名论坛爆料帖（游戏入口）
├── index.html          # 官网首页
├── services.html       # 服务介绍
├── menu.html           # 菜品展示（周三套餐大图藏批号）
├── feedback.html       # 家长反馈（加载更多藏匿名爆料）
├── contact.html        # 联系我们（源码注释藏密码规则）
├── staff-login.html    # 员工通道（密码 2015047）
├── 404.html            # 拟真 404（未授权访问内部页时跳转）
├── robots.txt          # Disallow: /internal/（暗示内部目录存在）
├── news/               # 4 篇新闻详情（消防演练报道与暗线互文）
├── internal/
│   ├── notice.html     # 内部公告栏
│   ├── yc-files.html   # 加密档案（口令 731）
│   └── choice.html     # 抉择与多结局
├── css/ js/            # 样式与交互逻辑
└── images/             # 全部图片已本地化，可离线运行
```

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，零依赖、零后端
- 进度状态存于 localStorage（`yc_tag` / `yc_staff` / `yc_files`），换浏览器会重置
- 内部页面有门禁校验，未解锁直接访问会跳转到 404 页（模拟真实网站"页面不存在"）
