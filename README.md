# 育儿小饭桌 · 沉浸式网页解谜游戏

## 游戏简介

你在深夜刷到一个匿名论坛的爆料帖：

> 建设路那家"育儿小饭桌"，水比你们想的深——周三的鸡排有怪味；中午不午睡的孩子要去"罚站思过"；9月店庆捐的款从没见过明细；报名第二天就接到培训机构电话；还有那个保育员刘姨，怎么看怎么像通缉令上的人……

帖子里附了那家机构的官网链接。网站看起来一切正常——温馨的饭菜、热情的师资、满屏的家长好评。

但真的是这样吗？

你将扮演一名普通网民，**像浏览真实网站一样**，在这家托管机构的官网里翻找蛛丝马迹：五条独立的线索线，五种完全不同的破解方式，最终拼出047店背后的完整黑幕。

- 类型：沉浸式网页解谜 / 剧情推理
- 时长：约 30 - 60 分钟
- 结局：**18 个**（5 条线索线 × 3 结局 + 总结线 3 结局，含 1 个隐藏真结局）
- 特色：无任何游戏化 UI，整个游戏就是一个"真实的网站"

## 运行方式

纯静态网页，无需安装任何东西：

- **方式一（推荐）**：双击打开 `forum.html`（论坛爆料帖，游戏的起点）
- **方式二**：本地起个静态服务
  ```bash
  python -m http.server 8000
  # 然后浏览器访问 http://localhost:8000/forum.html
  ```

推荐浏览器：Chrome / Edge / Firefox。

## 玩法教程（无剧透）

1. **从论坛开始**。先读 `forum.html` 的爆料帖和回复，楼里藏着每一条线的调查方向。
2. **把它当成真网站用**。五个栏目都要逛，真实网站上的点击、翻页、看大图，都可能触发线索。
3. **注意页脚的灰色小字**。有些公示链接做得越不起眼，越值得点进去。
4. **看源码**。真实的网民会右键"查看网页源代码"——网管有把备忘写进注释的习惯。
5. **口令都藏在公开信息里**。每条线的口令来源都不一样：有的是时间，有的是数字组合，有的是工号，多看多对照。
6. **卡住了就硬试**。每个口令输错 3 次后页面都会给提示，不存在死胡同。
7. **集齐五条线再去总结**。内部公告栏的"年终总结"需要五条业务线的材料都到手才能看全。
8. **论坛那个话题标签别漏**。它决定了你能否打出唯一的真结局。

## 文件结构

```
├── forum.html          # 匿名论坛爆料帖（游戏入口，含 #黑饭盒# 标签）
├── index.html          # 官网首页
├── services.html       # 服务介绍（师资墙藏刘姨工号、午休监控入口）
├── menu.html           # 菜品展示（页底藏留样记录入口）
├── feedback.html       # 家长反馈（加载更多藏匿名爆料）
├── contact.html        # 联系我们（源码注释藏员工口令+名单对接口令）
├── donate.html         # 募捐公示页（藏内网台账入口）
├── staff-login.html    # 员工通道（口令 04709）
├── ending.html         # 结局展示页（?e=1~18）
├── 404.html            # 拟真 404（门禁跳转用）
├── robots.txt
├── news/               # 4 篇新闻（食安满分/启航合作/店庆募捐/刘姨评优，均与暗线互文）
├── internal/
│   ├── notice.html     # 内部公告栏（6 条公告）
│   ├── kitchen.html    # 后厨证据 → e1-3
│   ├── cctv.html       # 午休监控（口令 1230）→ e4-6
│   ├── ledger.html     # 捐款台账（口令 1109）→ e7-9
│   ├── partner.html    # 名单对接（口令 1247）→ e10-12
│   ├── hr.html         # 人事档案（口令 009）→ e13-15
│   └── summary.html    # 年终总结（需集齐 5 线钥匙）→ e16-18
├── css/ js/            # 样式与交互逻辑（18 结局数据在 js/game.js）
└── images/             # 全部图片已本地化，可离线运行
```

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，零依赖、零后端
- 进度状态存于 localStorage（`xft_staff` / `xft_tag` / `xft_k_*`），换浏览器会重置
- 内部页面有员工门禁，未登录直接访问会跳转到 404 页（模拟真实网站"页面不存在"）
- 总结页自动统计已收集线索数，未集齐时会给出各线入口提示
